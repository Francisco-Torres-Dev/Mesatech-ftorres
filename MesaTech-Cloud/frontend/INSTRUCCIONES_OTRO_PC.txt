--------------------------------------------------------------------------------
PASOS PARA EJECUTAR:
--------------------------------------------------------------------------------
1. Descomprime este archivo ZIP en cualquier carpeta de tu computador.

2. Abre una terminal (PowerShell, CMD o Terminal) en esa carpeta descomprimida.

3. Instala las dependencias necesarias ejecutando:
   npm install

4. Inicia la aplicación en modo desarrollo:
   npm run dev

5. Abre tu navegador web en la dirección que te indique la consola:
   http://localhost:5173
